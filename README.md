# Muhammad Mussab Bin Asad Portfolio

A modern personal portfolio website built with HTML, CSS, and vanilla JavaScript. The site is designed to be production-ready and suitable for deployment to GitHub Pages.

## Project structure

- `index.html` — Main portfolio page.
- `style.css` — Site styling and responsive layout.
- `script.js` — Interactive behavior, animations, and scroll effects.
- `assets/images/` — Placeholder images and icons.
- `assets/icons/` — SVG icons and favicon files.
- `resume/` — Resume download file.
- `404.html` — Custom 404 error page.
- `robots.txt` — Crawl instructions.
- `sitemap.xml` — Sitemap for search engines.
- `manifest.json` — Web app manifest.

## Deployment

This portfolio is ready to deploy to GitHub Pages. Place the contents of the `portfolio` folder in a repository, and configure GitHub Pages to serve from `main` or `gh-pages`.

## Deployment instructions

1. Create a GitHub repository and push this folder to the `main` branch.
2. Open **Settings > Pages**.
3. Select **Branch: main** and **Folder: / (root)**.
4. Save and wait for GitHub to publish the site.
5. Visit the provided URL, usually `https://YOUR_USERNAME.github.io/portfolio/`.

## Optional custom domain (`CNAME`)

If you want to use your own domain, create a file named `CNAME` at the repository root and add your domain on a single line, for example:

```
www.example.com
```

Then set the same domain in GitHub Pages settings and add the matching DNS records with your domain provider.
